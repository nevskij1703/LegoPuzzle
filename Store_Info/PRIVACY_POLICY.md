# Политика конфиденциальности приложения «Лего-паззл»

Эта страница описывает, какие данные собираются при использовании мобильного приложения «Лего-паззл» (далее — «Приложение») и как они обрабатываются.

## Кто разработчик

Приложение разработано индивидуальным разработчиком (далее — «Разработчик»). Связь: terekh-spb@mail.ru.

## Какие данные собирает само Приложение

**Никаких персональных данных Приложение не собирает и не передаёт.**

Внутри устройства Приложение хранит только локальный игровой прогресс (`localStorage` WebView): пройденные уровни, настройки звука. Эти данные:

- хранятся **только на устройстве пользователя**;
- не передаются ни Разработчику, ни третьим лицам;
- удаляются при удалении приложения (Android system reset);
- могут быть очищены пользователем через системные настройки приложения.

## Какие данные собирают встроенные сервисы

В текущей версии Приложение **не использует встроенные рекламные SDK, аналитику или сторонние backend-сервисы**.

При добавлении в будущих версиях рекламы (Yandex Mobile Ads или аналогичной) этот раздел будет обновлён, и URL политики на странице магазина — также. Пользователю стоит сверяться с актуальной редакцией политики.

## Возрастные ограничения

Приложение предназначено для всех возрастов (категория 0+).

## Права пользователя

Пользователь имеет право:

- **Удалить локальные данные**: настройки Android → Приложения → «Лего-паззл» → Хранилище → «Очистить данные», либо просто удалить приложение.
- **Связаться с Разработчиком** по любым вопросам: terekh-spb@mail.ru.

## Cookies, аналитика, серверный обмен

Приложение **не использует**:
- Cookies (WebView хранит только localStorage внутри приложения).
- Сервисы аналитики (Google Analytics, AppMetrica, Firebase и т.п.).
- Собственный backend / API.
- Авторизацию через email, телефон, соцсети.
- Push-уведомления.
- Геолокацию.

## Изменения политики

Разработчик может обновить эту политику. Существенные изменения будут сопровождаться повышением версии приложения в магазине и публикацией новой версии этого файла в облачном хранилище (URL остаётся прежним).

## Контакты

По вопросам обработки данных, удаления или жалобам: terekh-spb@mail.ru.

## Как захостить эту политику (для разработчика)

РуСтор требует публичный URL политики конфиденциальности при публикации. Самый простой способ — **облачное хранилище**:

### Вариант A (рекомендуется): облако с публичной ссылкой

1. Открой `PRIVACY_POLICY.pdf` (этот файл — соседний с .md в `Store_Info/`). Если когда-нибудь нужно обновить — отредактируй .md, и попроси Claude перегенерировать .pdf.
2. Загрузи `PRIVACY_POLICY.pdf` в облако:
   - **Cloud Mail.ru** (cloud.mail.ru) — твоя почта `terekh-spb@mail.ru` уже привязана.
   - **Yandex Disk** (disk.yandex.ru).
   - **Google Drive** (drive.google.com).
3. Создай **публичную ссылку**: правый клик → «Поделиться» → «Получить ссылку» (доступ «по ссылке кому угодно»).
4. Скопируй URL — это и есть твой `privacyUrl` для РуСтор.
5. Впиши URL в `Store_Info/STORE_LISTING.md` → раздел «Контакты разработчика» → privacyUrl.

### Вариант B: GitHub Pages

Альтернатива если хочешь полноценную веб-страницу. Положи `.md` в публичный репозиторий, включи Pages.
