# Лего-паззл

Спокойная головоломка-сортировщик: расставь круглые цветные «лего-детали» по подложкам нужного цвета на пиксельной картинке.

Веб-приложение на vanilla JS, упаковывается в Android APK через Html2Apk Builder, публикуется в РуСтор.

## Быстрый старт

Открой [index.html](index.html) в браузере (двойной клик), либо подними локальный сервер:

```powershell
python -m http.server 8774
```

Затем `http://localhost:8774/` (или `?dev=1` для dev-панели).

## Как играть

1. На главной нажми **Играть**.
2. На поле видишь пиксельную картинку — это **финальный вид**. На каждом цветном пикселе стоит круглая деталь, но цвета деталей перемешаны.
3. **Тапни** на деталь — она и все соседние того же цвета (8-связность, включая диагонали) подсветятся.
4. **Тапни** на пустую подложку нужного цвета — детали переедут туда. Если в выбранной группе деталей больше чем места в целевом кластере — поедет столько, сколько влезет, остаток останется выделен.
5. Если рядом некуда поставить — **тапни на пустой слот инвентаря** внизу (12 ячеек), детали лягут туда.
6. Чтобы вернуть деталь из инвентаря — **тапни на неё**, она выделится вместе со всеми того же цвета в инвентаре, после чего тапни на нужное место.
7. **Цель**: все детали на своих цветах, инвентарь пуст.
